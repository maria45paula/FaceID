# FaceAccess - Sprint "Registro y acceso del personal"

1. Instalar Node.js (https://nodejs.org, versión LTS).
2. En MySQL Workbench ejecutar: faceaccess_completo.sql y luego ajuste_bd.sql
3. En db.js cambiar TU_CLAVE por la clave de su MySQL.
4. En una terminal, dentro de esta carpeta:
   npm install
   npm start
5. Abrir http://localhost:3000/login.html
